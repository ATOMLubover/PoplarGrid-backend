# 用户故事记录

## 创建项目

### 1. 创建者创建项目

创建者在 web 上创建一个新 project，此时他的 project labor 自动变成 creator（等价于负责人）

创建者可以指定：

- 项目 title（*）
- 图源文件（可选）

### 2. 指派职责

creator 可以在创建的同时，指定如下项目成员：

- translator（翻译，可选）
- proofer（校对，可选）
- letterer（嵌字，可选）
- reviewer（审核，可选）
- publisher（发布者，可选）`publisher 应该是在 e 站有代币的成员，理论上可以通过限定成员的 publisher 资格来控制`

上述人员指派中，是向特定成员发出加入邀请，接受邀请后才会正式加入。`考虑这样一种情况，某个被邀请的成员没有走同意申请加入项目，而是走正常申请加入项目的渠道，此时应该直接同意其加入，而无需再由 creator 进行审核。`
