# 要求

- [ ] 1. 项目编号：保留旧项目标题中的【】包裹的数字，作为legacy_id。所有项目重新标号。新项目只拥有主键标号作为项目id。创建新项目的时候，自动分配一个id，确保不会重复。
- [ ] 2. 项目状态：数据库使用多字段存储，加快效率，不需要掩码。前端在查询的时候，使用掩码，支持符合条件查询。
- [ ] 3. 项目的状态变更：对应职位的成员加入之后，项目的对应阶段不会立刻显示为“正在进行”，而仍旧是“未开始”。只有在点击了对应的按钮，开始工作之后，才标记为“正在进行”。
- [ ] 4. 成员加入项目：所有人可以点击任何项目进行查看。只有点击“加入项目”按钮，才能对项目的文本、状态等进行修改。对于没有某一项能力（在user表中查看用户能力）的用户，不允许其作为对应角色加入项目。另外，对于已经完成某一阶段的项目，也不允许其他成员以对应身份加入项目。
- [ ] 5. 审核加入申请：创建者、负责人，这二个角色可以负责处理加入申请。项目默认要经过审核才能加入，或者通过接受负责人的邀请。项目可以通过按钮选择是否需要审核加入申请。
- [ ] 6. 隐藏项目（先不做）：创建项目时设立一个隐藏项目的按钮，非受邀不可见，需完成之后才可显现。网站管理员可以查看所有隐藏项目；只有网站管理员才能创建隐藏项目。
- [ ] 7. 邀请加入项目：负责人、创建者可以邀请成员加入项目。在邀请时，选择需要邀请的成员，以及其需要担任的职位。通过点击邀请按钮，直接在网站上向对方发送邀请；（先不做）也可以生成邀请链接，收到的人通过访问该链接可以加入项目，并自动获取对应的职责。
- [ ] 8. member所属团队：需要新创建一张表格。
- [ ] 9. 不同团队的项目id：为每一个团队维护一个总项目数，在创建新项目的时候将这个数字+1作为在组内显示的id，并将这个数字+1。在前端发送请求的时候使用主键作为参数，而不是这个总项目数。
